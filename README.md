# Build It Forward — Homeowner Portal (Prototype)

A clickable prototype of the Build It Forward homeowner portal, showing:

- **Dashboard**: Home Health Score™, active project, upcoming maintenance, HomeCare™ membership
- **Digital Home Passport™**: property details, major systems, warranties, receipts, photos and selections
- **My Project**: lifecycle stage tracker, project updates and next steps
- **Home Investment Roadmap™**: 1-, 3- and 5-year plan with planning-range budgets
- **Maintenance Calendar**: seasonal tasks that raise the Home Health Score
- **Request Service**: intake form for repairs, remodels, maintenance, emergencies and second opinions
- **HomeCare™ Membership**: Essential, Plus and Premier tiers

## Running it

It is a single `index.html` file with no build step. Open it in any web browser.

To put it online with GitHub Pages: open the repository's **Settings → Pages**, set the source to the `main` branch and the `/ (root)` folder, then save. The site will appear at `https://<your-username>.github.io/<repo-name>/`.

## Notes

- All data is sample data for a fictional homeowner.
- Changes (checked tasks, new records, requests) are saved only in the viewer's own browser. Use **Reset sample data** in the sidebar to start over.
- Requests and messages are not sent anywhere. This is a prototype for demos and customer feedback, not a production system.
- The Home Health Score™ is a maintenance-planning tool, not a home inspection, engineering opinion, code certification, appraisal or guarantee of safety.
